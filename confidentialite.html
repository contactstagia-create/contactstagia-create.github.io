Politique de confidentialité

Dernière mise à jour : octobre 2026

Principes généraux

Stagia accorde une importance particulière à la protection de votre vie privée. Les applications Android GigFlow Live et InBeat fonctionnent entièrement hors ligne, et les outils web (GigFlow Editor, InBeat dans le navigateur) s'ouvrent dans votre navigateur sans compte — dans tous les cas, vos chansons, setlists et données musicales ne quittent jamais votre appareil et ne sont transmises à aucun serveur.

Ce site web (stagia.app) utilise, uniquement avec votre consentement, des outils de mesure d'audience décrits ci-dessous.

Applications InBeat, GigFlow Live et GigFlow Editor

Cette section couvre les applications Android InBeat: Live Tempo Manager (com.stagia.inbeat) et GigFlow Live: Music Manager (com.stagia.gigflow.live), ainsi que les outils web GigFlow Editor et InBeat dans le navigateur.

  • Aucune donnée collectée par les applications Android. InBeat et GigFlow Live ne collectent, ne transmettent et ne partagent aucune donnée personnelle ni donnée d'usage. Elles ne contiennent aucun outil d'analyse, aucune publicité, aucun SDK tiers de mesure. Les outils web GigFlow Editor et InBeat dans le navigateur, hébergés sur stagia.app, relèvent du site : leur mesure d'audience est décrite dans la section « Données collectées sur ce site ». Cette différence est volontaire : aucune collecte dans les applications Android, une mesure d'audience soumise à votre consentement sur le web.
  • Vos données musicales restent chez vous. Les applications Android GigFlow Live et InBeat fonctionnent 100 % hors ligne. GigFlow Editor et InBeat dans le navigateur n'envoient jamais vos chansons, setlists, tempos ni réglages à un serveur. Ils sont stockés uniquement en local, sur votre appareil (dans le navigateur pour GigFlow Editor et InBeat dans le navigateur, via le stockage local du navigateur et, pour InBeat, une copie de l'application conservée pour le fonctionnement hors ligne). Un navigateur peut effacer ces données ; exportez-les régulièrement.
  • Pas de compte. Aucune inscription, aucun identifiant, aucune adresse e-mail ne sont demandés pour utiliser les applications.
  • Aucune permission sensible. Les applications n'accèdent ni à votre position, ni à vos contacts, ni au microphone, ni à la caméra, ni à vos fichiers en dehors des imports/exports que vous déclenchez vous-même.
  • Vous gardez le contrôle. Les fonctions d'export (fichiers JSON, .inb ou HTML) sont déclenchées manuellement par vous et produisent des fichiers qui restent sous votre responsabilité. La désinstallation d'une application supprime l'ensemble de ses données locales.

En résumé : vos données musicales vous appartiennent et ne quittent jamais votre appareil.

Données collectées sur ce site

Le site stagia.app, y compris les outils web GigFlow Editor et InBeat dans le navigateur, utilise les outils suivants à des fins de mesure d'audience (statistiques agrégées établies à partir de données pseudonymisées). Pour GigFlow Editor, seuls l'ouverture de l'outil et le type d'export réalisé (sauvegarde, titres, setlists, base d'accords ou PDF de setlist) sont comptés ; pour InBeat dans le navigateur, seuls l'ouverture de la version web et le fait de l'ajouter à l'écran d'accueil (une fois par appareil) sont comptés. Dans les deux cas, ces comptages ne sont effectués que si vous avez accepté la mesure d'audience dans le bandeau (base légale : votre consentement) : jamais le contenu de vos chansons ni de vos setlists.

Google Analytics 4 (GA4)

Mesure de l'audience : pages visitées, durée des sessions, provenance géographique approximative. Les résultats nous sont restitués sous forme de statistiques agrégées ; Google traite toutefois, pour le compte de Stagia, des données pseudonymisées (identifiant de cookie, adresse IP, appareil et navigateur) dans le cadre de cette mesure. Ces données ne sont collectées qu'après votre acceptation. Politique de confidentialité : policies.google.com/privacy

Google Tag Manager (GTM)

Outil de gestion des balises de mesure. GTM lui-même ne collecte pas de données — il orchestre le déclenchement de GA4. Il n'est chargé qu'après votre acceptation. Politique de confidentialité : policies.google.com/privacy

YouTube — vidéos intégrées

Certaines pages du site (par exemple une vidéo de présentation ou des tutoriels) intègrent des vidéos hébergées sur la chaîne YouTube de Stagia, via le mode de confidentialité renforcé (youtube-nocookie.com). Les vidéos ne sont chargées qu'après votre clic sur « Lire la vidéo » ; avant ce clic, aucune connexion n'est établie avec YouTube. Une fois la vidéo chargée, votre navigateur se connecte aux serveurs de YouTube (Google), qui peuvent traiter votre adresse IP et utiliser des cookies ou identifiants techniques selon leur propre politique. Stagia ne reçoit aucune donnée personnelle à ce titre. Ces vidéos concernent uniquement le site : les applications Android n'en intègrent aucune. Politique de confidentialité : policies.google.com/privacy

GitHub Pages — hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc., États-Unis). L'hébergeur reçoit votre adresse IP à chaque visite et la conserve dans ses journaux techniques selon sa propre politique, indépendamment de votre choix dans le bandeau. Politique de confidentialité : docs.github.com

Transferts hors Union européenne. Google (GA4, GTM, YouTube) et GitHub sont établis aux États-Unis. Ces transferts reposent sur les garanties prévues par le RGPD (décision d'adéquation du cadre de protection des données UE–États-Unis pour les prestataires certifiés, ou clauses contractuelles types), selon le prestataire ; leurs politiques de confidentialité en donnent le détail.

Aucune autre donnée n'est collectée par Stagia. Stagia n'utilise ni cookie publicitaire, ni tracking inter-sites, ni formulaire de création de compte ; seules les vidéos YouTube intégrées ci-dessus relèvent de la politique de Google.

Cookies

Ce site utilise des cookies de mesure d'audience (Google Analytics), non nécessaires au fonctionnement du site et soumis à votre consentement : un bandeau vous permet d'accepter ou de refuser dès votre première visite. Si vous acceptez, Google Tag Manager et Google Analytics sont chargés et des cookies de mesure sont déposés. Ces cookies (_ga et _ga_ suivi d'un identifiant) ont une durée de vie de 13 mois à compter de votre première visite ; elle n'est pas prolongée par vos visites suivantes. Si vous refusez, rien n'est chargé ni envoyé à Google pour la mesure d'audience et aucun cookie de mesure n'est déposé. Vous pouvez changer d'avis à tout moment avec le lien « Gérer les cookies » présent en bas de chaque page, ou ici : Gérer les cookies ; retirer votre consentement supprime les cookies de mesure. Aucun cookie publicitaire n'est déposé par Stagia ; les vidéos YouTube intégrées peuvent en revanche déposer leurs propres cookies lors de la lecture (voir ci-dessus). Vous pouvez aussi bloquer ces cookies via les paramètres de votre navigateur ou une extension de blocage (uBlock Origin, etc.). Par ailleurs, GigFlow Editor et InBeat dans le navigateur utilisent le stockage local de votre navigateur (et, pour InBeat, un cache de l'application pour le mode hors ligne) afin de conserver vos données et réglages ; ce stockage est nécessaire au fonctionnement, reste sur votre appareil et ne sert à aucun suivi.

Durée de conservation

Les données de navigation pseudonymisées collectées par Google Analytics (après votre acceptation) sont conservées pendant 14 mois, conformément au réglage de conservation défini dans notre compte Google Analytics, puis supprimées automatiquement.

Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès — connaître les données collectées vous concernant
  • Droit de rectification — corriger des données inexactes
  • Droit à l'effacement — demander la suppression de vos données
  • Droit d'opposition — vous opposer au traitement de vos données
  • Droit à la limitation — demander le gel temporaire d'un traitement
  • Droit à la portabilité — récupérer vos données dans un format courant, lorsque le traitement repose sur votre consentement
  • Retrait du consentement — à tout moment, avec le lien « Gérer les cookies », sans effet sur ce qui a été fait avant le retrait
  • Directives après décès — définir le sort de vos données après votre décès

Pour exercer ces droits (nous répondons dans un délai d'un mois), contactez-nous à contact@stagia.app. Vous pouvez également adresser une réclamation à la CNIL.
